# Security

This project is an experimental kernel, not a supported production isolation
boundary. The v0.1.0 research preview is intended for controlled QEMU testing.
See [the threat model](docs/M7-THREAT-MODEL.md) for the tested scope and assumptions.

For a suspected vulnerability, use GitHub's **Security → Report a vulnerability**
for this repository. Include the affected commit, QEMU configuration, a minimal
reproducer, expected/observed behavior, and relevant logs with secrets removed.

There is no guaranteed response time, security-update schedule, or bug bounty.
Do not include credentials or details of unrelated private systems in a report.
